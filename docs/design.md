# 词阶设计与实施记录

日期：2026-10-10。此项目独立于原工作区项目；代码仓库 IXYTYXI/sej，不依赖飞书。

## 已确认需求

独立网页，同时适配手机与电脑；英语、日语使用网上已有词库；后台准备大量词库，通过等级限制下一词库访问。用户选择：当前词库掌握至少 80%，且通过过关测试后才能继续。

## 第一版默认规则

每阶段约100词，测试20题（尾部小关卡取实际词数），得分不低于80%。词书拆分小阶段，英语基础之后允许考试分支，日语五个级别顺序连接。单词ID按语言及词形（含日语读音）去重，统计词汇量不累加重复词书词位。

FSRS以90%目标记忆率排程。掌握需首次学习距今7天、至少3个不同日期成功回忆、最后一次评分至少Good且间隔至少7天。忘记后成功日期清零；解锁奖励不会撤回。每天每种语言10个新词，可调5–50，先复习后新学。

## 架构与数据

响应式React界面调用鉴权API。所有学习状态保存在D1，浏览器只保留当前界面状态。词库由服务器加载，客户端无法通过API读取锁定阶段；服务器自行确认日期、门槛与答案。Sites提供私人访问及账号身份，不接入飞书。

`scripts/build_vocab.py`负责来源转换，`data/catalog.json`是带版本来源的确定性产物。`lib/progression.ts`负责间隔与掌握规则，`lib/server*.ts`负责身份、SQL读写和接口逻辑，`lib/exams.ts`负责题目与计分，`app/components/`负责展示。SQL schema及迁移保存在`db/`和`drizzle/`。

## 实施与验证计划

1. 导入完整来源，验证词条ID、中文释义、去重、阶段依赖无环及来源许可；运行数据测试。
2. 对80%边界、同日刷词、遗忘后重学及永久解锁先写失败测试，再实现FSRS与掌握计算。
3. 鉴权API采用参数化SQL。复习用版本CAS和请求ID避免重复计数；考试答案只存服务器，提交与解锁原子执行。
4. 实现今日、词库、学习、考试、进度、设置，处理无数据、无语音、登录过期、冲突及网络重试。
5. 运行类型检查、单测、实际本地D1接口测试和手机/桌面浏览器检查；模拟解锁结果只写本地测试数据库。
6. 推送源码到用户指定GitHub仓库，以私人方式部署网站。数据规模以data/stats.json为准，交付中注明未验证或不可用能力。

## 验收重点

未登录不能读写进度；未掌握80%不能参加考试；未通过考试不能开下一关；重复/并发提交不重复累计；跨设备旧版本不覆盖新进度；英语记录不影响日语；私人学习数据不进入Git仓库。
