# 词阶设计与实施记录

初版日期：2026-10-10；规则更新：2026-10-16。此项目独立于原工作区项目；代码仓库 IXYTYXI/sej，不依赖飞书。

## 已确认需求

独立网页，同时适配手机与电脑；英语、日语使用网上已有词库；后台准备大量词库，通过阶段测验限制下一阶段访问。2026-10-16 用户确认：学完当前阶段全部词条即可考试，通过后解锁下一阶段；掌握率单独按间隔复习统计，不作为学习或考试门槛。这取代初版的 80% 掌握率门槛。

## 当前学习与解锁规则

每阶段约100词，测试20题（尾部小关卡取实际词数），得分不低于80%。词书拆分小阶段，英语基础之后允许考试分支，日语五个级别顺序连接。单词ID按语言及词形（含日语读音）去重，统计词汇量不累加重复词书词位。

“已学习”表示已存在该词的正式学习记录，不要求某个评分。阶段全部词条均已学习时即可考试，即使掌握率为 0%、首次学习还不到一天。考试达到 80% 正确率后永久解锁后续阶段；考试未通过可以重试，不清空学习记录。已有账号直接复用原学习记录，无需重新学习或迁移数据。

FSRS以90%目标记忆率排程。掌握需首次学习距今7天、至少3个不同日期成功回忆（首次学习可计一次，之后须为到期复习）、最后一次评分至少Good且间隔至少7天。忘记后成功日期清零，但不影响考试资格或已获得的解锁。每天每种语言10个新词，可调5–50，先复习后新学。每日额度、三次提升机会与跨天保留/重置规则保持独立。

页面以已学习词数和学习进度展示考试资格，另外显示长期掌握率。已学完时明确展示阶段测验入口，不能因为存在到期复习而隐藏；通过测试不伪造掌握率，自主练习不写入正式复习记录。

## 架构与数据

响应式React界面调用鉴权API。学习状态保存在自有服务器 Docker 的 SQLite 持久卷，浏览器只保留当前界面状态。词库由服务器加载，客户端无法通过API读取锁定阶段；服务器自行确认日期、阶段学习记录与答案。账号使用独立登录和邀请码注册，不依赖 Sites 身份或飞书。

`scripts/build_vocab.py`负责来源转换，`data/catalog.json`是带版本来源的确定性产物。`lib/progression.ts`负责间隔与掌握规则，`lib/server*.ts`负责身份、SQL读写和接口逻辑，`lib/exams.ts`负责题目与计分，`app/components/`负责展示。SQL schema及迁移保存在`db/`和`drizzle/`。

## 实施与验证计划

1. 导入完整来源，验证词条ID、中文释义、去重、阶段依赖无环及来源许可；运行数据测试。
2. 对阶段 99/100 与 100/100 已学习边界、当天掌握率 0% 即可考试、80% 测验通过线、遗忘不撤回资格及永久解锁先写失败测试；保留 FSRS 掌握计算测试。
3. 鉴权API采用参数化SQL。复习用版本CAS和请求ID避免重复计数；考试答案只存服务器，提交与解锁原子执行。
4. 实现今日、词库、学习、考试、进度、设置，处理无数据、无语音、登录过期、冲突及网络重试。
5. 运行 ESLint、类型检查、单测、实际本地 SQLite 接口测试和手机/桌面浏览器检查；模拟解锁结果只写临时测试数据库。
6. 推送源码到用户指定GitHub原分支，备份数据库后更新自有服务器的 Docker 部署。数据规模以data/stats.json为准，交付中注明未验证或不可用能力。

## 验收重点

未登录不能读写进度；阶段未全部学完不能考试，全部学完且掌握率为 0% 时可以考试；未通过考试不能开下一关；测验通过不改变掌握率；重复/并发提交不重复累计；跨设备旧版本不覆盖新进度；英语记录不影响日语；私人学习数据不进入Git仓库。
