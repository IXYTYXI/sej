# Docker 独立部署与 AI 学习功能

**目标：** 将词阶部署到 `https://xairlab.com/study`，由自有服务器 Docker 运行，保留既有学习规则，增加报告、单词解释和对话练习。

**架构：** Next standalone / Node 24，SQLite 单副本持久化；固定个人账号与数据库会话；服务器配置 Anthropic / OpenAI 兼容接口。沿用既有反向代理，仅增加 `/study` 路由。API 密钥与登录凭证通过运行时秘密配置注入，不纳入 Git。

## 约定

- 学习算法与解锁由规则执行，模型不能改变掌握率或直接解锁关卡。
- AI 默认每账号每日 30 次、同时 1 个请求；中文解释，目标语言练习。
- 本版为个人学习使用，不开放注册。登录密码单独设置，不复用服务器密码。
- AI 提供者未配置独立 key 时显示未配置；不把网址当作密钥，也不静默使用另一提供者。
